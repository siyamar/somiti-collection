# 🌿 সবুজ বাংলা সমবায় সমিতি লিঃ (Somiti Collection System)
### দৈনিক কালেকশন, সঞ্চয় হিসাব ও মাঠকর্মী ফিল্ডওয়ার্ক ব্যবস্থাপনা সফটওয়্যার

একটি আধুনিক, নিরাপদ ও সম্পূর্ণ বাংলা ইন্টারফেসে নির্মিত সমিতি ও ক্ষুদ্রঋণ/সঞ্চয় কালেকশন ম্যানেজমেন্ট সিস্টেম। মাঠকর্মীদের জন্য ফিল্ডে মোবাইলে দ্রুত কালেকশন এন্ট্রি এবং অফিসে অ্যাডমিনদের জন্য নিখুঁত হিসাব, ৪টি পূর্ণাঙ্গ রিপোর্ট, এক্সেল এক্সপোর্ট, স্বয়ংক্রিয় বাংলা SMS এবং অডিট ট্রেইল সংবলিত।

## 🌟 প্রজেক্ট ওভারভিউ ও মূল বৈশিষ্ট্য

- **মাঠকর্মীর জন্য অপ্টিমাইজড মোবাইল এন্ট্রি:** মাঠকর্মীরা স্মার্টফোনে কোনো ঝামেলা ছাড়া একহাতে দ্রুত সঞ্চয় এন্ট্রি করতে পারেন। এক ট্যাপে নির্ধারিত পরিমাণ বা ০ (দেননি) বসানো এবং মন্তব্য লেখার সুবিধা।
- **ডেস্কটপ লেজার খাতা (Ledger Sheet):** লাল মার্জিন রেখা সংবলিত প্রথাগত খাতার আদলে টেবিল, কীবোর্ড নেভিগেশন (Tab/Enter) এবং স্বয়ংক্রিয় রিয়েল-টাইম হিসাব।
- **নিরাপদ দুই ধাপের কার্যপ্রক্রিয়া (Draft & Confirm):** যতক্ষণ না দিনটি নিশ্চিত করা হয়, ততক্ষণ এটি খসড়া থাকে। নিশ্চিত করার সাথে সাথে ডাটাবেস ট্রানজেকশনে সদস্যদের মোট হিসাব আপডেট হয় এবং স্ট্যাম্প সীলমোহর পড়ে।
- **স্বয়ংক্রিয় বাংলা SMS ওয়ার্কার:** দিন নিশ্চিত করার সাথে সাথে সদস্যদের মোবাইলে স্বত্বাধিকারী টেমপ্লেটে SMS পাঠানো হয়। ডেভেলপারদের জন্য `fake` টার্মিনাল মোড এবং প্রোডাকশনের জন্য যেকোনো আসল SMS গেটওয়ে ব্যবহারের সমর্থন।
- **অ্যাডমিন সংশোধন ও অডিট লগ:** নিশ্চিত করা দিন লক থাকে। তবে কোনো ভুল হলে অ্যাডমিন সুনির্দিষ্ট কারণ উল্লেখ করে সংশোধন করতে পারেন; সংশোধনের ইতিহাস সংরক্ষিত থাকে এবং সদস্যকে সংশোধিত SMS পাঠানো হয়।
- **৪টি পূর্ণাঙ্গ রিপোর্ট ও এক্সেল এক্সপোর্ট:** দৈনিক আদায় বিবরণী, মাসিক সারাংশ, অনাদায়ী/বকেয়া তালিকা এবং সদস্যদের চলমান ব্যালেন্স সম্বলিত পাসবুক স্টেটমেন্ট।
- **নিরাপত্তা ও অ্যাক্সেস কন্ট্রোল:** HTTP-only কুকি বেসড JWT প্রমাণীকরণ, রোল-বেসড অ্যাক্সেস (Admin & Collector) এবং প্রথম লগইনে বাধ্যতামূলক পাসওয়ার্ড পরিবর্তন।

## 💻 প্রযুক্তি স্ট্যাক (Tech Stack)

### ব্যাকএন্ড (Backend)
- **রানটাইম:** Node.js (ES Modules)
- **ফ্রেমওয়ার্ক:** Express.js 4.x
- **ডাটাবেস:** MySQL 8 (mysql2/promise সংযোগ পুল, ট্রানজেকশন ও রো-লেভেল লকিং)
- **নিরাপত্তা:** Helmet, CORS, Cookie-Parser, Bcrypt, Zod ভ্যালিডেশন
- **ব্যাকগ্রাউন্ড ওয়ার্কার:** Node-cron (SMS কিউ প্রসেসিং ও অটো রিট্রাই)
- **রিপোর্ট ও এক্সেল:** ExcelJS, Sharp (ছবি অপটিমাইজেশন), Multer

### ফ্রন্টএন্ড (Frontend)
- **লাইব্রেরি ও টুলিং:** React 18, Vite 6
- **স্টাইলিং:** Tailwind CSS (ডিজাইন টোকেন, কাস্টম ফন্ট ও কালার প্যালেট)
- **ফন্ট:** Hind Siliguri (মূল বাংলা পাঠ্য), JetBrains Mono (টাকার অংক ও কোড), Noto Serif Bengali (হেডিং ও ব্যানার)
- **আইকন:** Lucide React
- **সার্ভার স্টেট:** TanStack React Query & Axios (withCredentials: true)
- **গ্রাফ ও চার্ট:** Recharts (১৪ দিনের কালেকশন বার চার্ট)

## 🛠️ ইনস্টলেশন ও রান করার নিয়ম

### ১. পূর্বশর্ত
- আপনার কম্পিউটারে **Node.js (>= 18)** এবং **MySQL Server (>= 8.0)** ইনস্টল থাকতে হবে।

### ২. প্রজেক্ট ক্লোন ও ডিপেন্ডেন্সি ইনস্টল
```bash
cd "somiti-collection"
npm install
```

### ৩. ডাটাবেস তৈরি ও পরিবেশ কনফিগারেশন (`.env`)
MySQL সার্ভারে একটি ডাটাবেস তৈরি করুন:
```sql
CREATE DATABASE jomakhata CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

`backend/.env` ফাইলটি ওপেন করে আপনার ডাটাবেসের তথ্য দিন:
```env
PORT=4000
NODE_ENV=development
APP_URL=http://localhost:5173

DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_mysql_password
DB_NAME=jomakhata

JWT_SECRET=sobuj_bangla_samity_super_secure_secret_key_2026
SMS_DRIVER=fake
```

### ৪. ডাটাবেস মাইগ্রেশন ও ডেমো ডাটা সিড
```bash
# ডাটাবেস টেবিলসমূহ ও ডিফল্ট সেটিংস তৈরি করুন
npm run migrate

# অ্যাডমিন অ্যাকাউন্ট তৈরি করুন (নাম, মোবাইল নম্বর ও পাসওয়ার্ড চাইবে)
npm run seed:admin

# (ঐচ্ছিক) পরীক্ষার জন্য ১০ জন বাস্তবসম্মত সদস্য ও পূর্ববর্তী কালেকশন ডাটা যুক্ত করুন
npm run seed:demo
```

### ৫. প্রজেক্ট চালু করা
রুট ডিরেক্টরি থেকে একটি কমান্ডেই ব্যাকএন্ড এবং ফ্রন্টএন্ড একসাথে চালু হবে:
```bash
npm run dev
```

- **ওয়েব অ্যাপ (ফ্রন্টএন্ড):** [http://localhost:5173](http://localhost:5173)
- **ব্যাকএন্ড API:** [http://localhost:4000](http://localhost:4000)
- **API হেলথ চেক:** [http://localhost:4000/api/health](http://localhost:4000/api/health)

## 🎓 জুনিয়র ডেভেলপার গাইড ও আর্কিটেকচার

এই প্রজেক্টটি ইন্ডাস্ট্রির আধুনিক **Clean Layered Architecture** মেনে তৈরি করা হয়েছে। আপনি যেন প্রতিটি ফাইলের কাজ সহজে বুঝতে পারেন, নিচে একটি রিকোয়েস্টের জীবনচক্র ব্যাখ্যা করা হলো:

### রিকোয়েস্ট ফ্লো: `Route → Controller → Service → Database`

```
   Browser (React Client)
             │
             ▼ [HTTP Request - Cookie JWT]
    backend/src/routes/*.js             (ইউআরএল রাউটিং এবং অথেনটিকেশন মিডলওয়্যার)
             │
             ▼
 backend/src/controllers/*.js       (রিকোয়েস্ট ডাটা ও Zod ভ্যালিডেশন যাচাই)
             │
             ▼
   backend/src/services/*.js          (ব্যবসায়িক লজিক, গণনা ও SMS টেমপ্লেট রেন্ডার)
             │
             ▼
      MySQL 8 Database                 (SQL কুয়েরি, ট্রানজেকশন ও রো-লেভেল লকিং)
```

### গুরুত্বপূর্ণ ফাইল ও ফোল্ডার পরিচিতি:
- [`backend/src/config/db.js`](file:///run/media/hp/New%20Volume/ASUS%20VivoBook/project/somiti-collection/backend/src/config/db.js): MySQL কানেকশন পুল। এখানে `decimalNumbers: true`, `dateStrings: ['DATE']`, এবং `timezone: '+06:00'` কনফিগার করা হয়েছে যেন টাকার পয়সা এবং বাংলাদেশ টাইমজোনের হিসাব ঠিক থাকে।

## ⚖️ অপরিবর্তনীয় ব্যবসায়িক নিয়মসমূহ (Business Rules)

এই সফটওয়্যারের ডাটা সঠিক রাখার জন্য নিচের নিয়মগুলো কখনোই পরিবর্তন করা যাবে না:
1. **শুধুমাত্র কনফার্ম করা দিনের ডাটাই বৈধ:** কোনো খসড়া (draft) কালেকশন সদস্যদের ব্যালেন্স, রিপোর্ট বা SMS-এ গণ্য হবে না।
2. **কখনোই সদস্য টেবিলে ব্যালেন্স জমা রাখা যাবে না:** সদস্যের মোট সঞ্চয় সর্বদা নিশ্চিত কালেকশন থেকে ডায়নামিক `SUM()` দিয়ে গণনা করা হয়:
   ```sql
   SELECT COALESCE(SUM(c.amount), 0)
   FROM collections c
   JOIN collection_days d ON d.id = c.day_id
   WHERE c.member_id = ? AND d.status = 'confirmed';
   ```
3. **এক দিনে একটি শিট:** প্রতিটি তারিখের জন্য ডাটাবেসে একটি মাত্র শিট থাকবে (`UNIQUE collect_date`)।
4. **ভবিষ্যতের তারিখ নিষিদ্ধ:** মাঠকর্মী শুধুমাত্র আজ এবং গতকালের তারিখ খুলতে পারেন। অ্যাডমিন পেছনের যেকোনো তারিখ দেখতে পারেন।
5. **কনফার্ম শিট রিড-অনলি:** একবার শিট কনফার্ম হয়ে গেলে সরাসরি সম্পাদনা নিষিদ্ধ। কেবল অ্যাডমিন সুনির্দিষ্ট কারণ উল্লেখ করে সংশোধন (`correction`) করতে পারেন এবং এর জন্য স্বয়ংক্রিয় নতুন SMS কিউ হয়।
6. **ডাটা ডিলিট নিষিদ্ধ:** কোনো সদস্য বা ইউজার ডাটাবেস থেকে ডিলিট করা হয় না; প্রয়োজনে নিষ্ক্রিয় (`inactive`) করা হয়।
7. **অটো ইনক্রিমেন্ট মেম্বার কোড:** মেম্বার কোড তৈরির সময় ডাটাবেসে `SELECT ... FOR UPDATE` ট্রানজেকশন লকিং ব্যবহার করা হয় যাতে একই কোড একাধিক সদস্য না পান (`M-0001`, `M-0002`...)।

## 📱 মোবাইল ফিল্ডওয়ার্ক গাইড

মাঠকর্মীরা যখন সাইকেল বা হেঁটে গ্রাহকদের বাড়ি বাড়ি গিয়ে টাকা আদায় করেন, তখন মোবাইল ভিউটি অত্যন্ত উপযোগী:
1. **প্রগ্রেস ট্র্যাকার:** স্ক্রিনের শীর্ষে লাইভ অগ্রগতি দেখা যায় (যেমন: `৭ / ১০ জন আদায় · ৭০%`)।
2. **এক ট্যাপে নির্ধারিত টাকা:** সদস্যের কার্ডে ট্যাপ করলে তা বড় হয়ে খোলে। সদস্য পুরো টাকা দিলে শুধু **"নির্ধারিত"** বাটনে চাপ দিলেই নির্ধারিত কিস্তি বসে যায়।
3. **অনুপস্থিত থাকলে:** **"০ (দেননি)"** চাপলে সরাসরি শূন্য হয়ে যায়।
4. **পরবর্তী সদস্য নেভিগেশন:** সদস্যের কাজ শেষ হলে কার্ডের নিচের **"পরবর্তী সদস্য →"** বাটনে চাপ দিলে স্বয়ংক্রিয়ভাবে পরের সদস্যের ইনপুট সক্রিয় হয়।
5. **নিশ্চিত ও SMS:** সকল সদস্যের আদায় শেষ হলে স্ক্রিনের নিচে স্থায়ী বারে **"নিশ্চিত ও SMS"** বাটনে ট্যাপ করে আজকের দিনের কাজ সমাপ্ত করা যায়।
